# Security policy

## Reporting a vulnerability

Please report security issues privately through GitHub: **Security → Report a vulnerability**
on this repository. Do not open a public issue.

You can expect an acknowledgement within 5 working days and a status update within 14.
Accepted issues are fixed or recorded as accepted risks in the risk register
(NIST CSF 2.0 RS.AN-05, RS.MI-03).

## Scope

This repository is an educational simulation. The Terraform targets LocalStack by default and
contains placeholder account IDs and names; there is no production system behind it.
Reports about the code, the CI pipeline or the policies in `policy/` are welcome.
