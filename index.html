Simulated AWS FinTech platform

A risk assessment of a deliberately misconfigured AWS environment, the Terraform that fixes it, and the scan evidence that proves it. Every finding below links to the code change, the NIST controls it supports, and the tool output it is based on.

Executive summary

Scope & method

  • Environment: Terraform for AWS, deployed against LocalStack. No real AWS account or customer data.
  • Scoring: 5×5 likelihood × impact using the five qualitative levels of NIST SP 800-30 Rev. 1 (Very Low → Very High). Likelihood and impact ratings are the assessor's judgment; the rationale is recorded for each.
  • Evidence: Checkov and this repository's scan.py, run against the vulnerable baseline and the hardened code.
